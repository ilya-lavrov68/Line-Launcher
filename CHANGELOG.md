# История версий

Номер версии задаётся **только** в `version.json`. Всё остальное — `package.json`,
`src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.lock`,
подпись в интерфейсе и интерфейс «О программе» — выводится из него:

```bash
npm run version:sync          # проставить текущий номер во все файлы
npm run version:sync 0.11.0   # поднять версию и проставить везде
npm run version:check         # проверить, что нигде не разъехалось
```

`npm run build` начинается с `version:check`, поэтому собрать установщик с
расходящимися номерами нельзя: сборка остановится и покажет, какой файл отстал.

Теги в git повторяют номер: `v0.10.0`. Он же уходит в проводник и в установщик —
через `Cargo.toml`, который читает Tauri.

## Как выбирается номер

SemVer, `МАЖОР.МИНОР.ПАТЧ`:

- **ПАТЧ** — исправление, которое не меняет ничего, кроме поведения: баг,
  вёрстка, перевод.
- **МИНОР** — новая возможность: новый раздел, новый параметр в конфиге
  провайдера, новый формат.
- **МАЖОР** — несовместимость: старый конфиг провайдера перестаёт грузиться,
  меняется формат рецепта сборки, ломается совместимость с уже установленными
  сборками.

Пока мажор равен `0`, совместимость не обещана — такая сборка помечается в
интерфейсе как предварительная.

## 0.10.0 — 2026-11-11

Первая версия, у которой есть номер, совпадающий с содержимым: до неё везде
стояло `0.1.0`, хотя сборка давно ушла вперёд.

### Исправлено

- **«Гардероб» выкидывал из аккаунта.** Экран при открытии сам отправлял скин на
  сервер и на любую ошибку вызывал выход из сессии. Теперь сбой показывается в
  строке состояния синхронизации, а сессия остаётся.
- **Кнопка «Попробовать снова» выкидывала из аккаунта «с неким шансом».** Причин
  было две: `AuthRequired` использовался и для устаревшей конфигурации
  провайдера, и для сбоев приватного канала с модом, а интерфейс на этот код
  стирал сессию. Теперь `AuthRequired` означает только 401/403 или отсутствие
  сессии, остальное приходит как `Busy`, а перед выходом интерфейс спрашивает
  бэкенд, жива ли сессия.
- **Крестик в шапке был тусклым при наведении.** Значок рисовался красным по
  красному (контраст 1.23:1) — теперь заливка глубокая и насыщенная, а крестик
  остаётся красным, но заметно светлее её.
- **Конфигурация не обновлялась перед запуском, установкой и гардеробом** —
  только при входе. Из-за этого действие через пять минут после открытия окна
  падало с ошибкой, которую на этом экране нельзя было исправить.

### Изменено

- **Фон стал темнее и живее.** Все двенадцать градиентов дрейфовали одинаково и
  медленно; теперь они идут в трёх разных режимах, примерно вдвое быстрее, а
  затемнение поднято с 0.26–0.46 до 0.42–0.60, чтобы панели читались.
- **Версия лаунчера.** Единый источник номера, проверка расхождений при сборке,
  подпись версии в интерфейсе и «О программе», канал сборки.

### Добавлено

- `version.json` и `scripts/version.mjs` — единый источник версии и её
  синхронизация.
- `CHANGELOG.md` — этот файл.
- Пометка предварительной сборки в подвале и в «О программе».
