# Состояния установки

Подпись главной кнопки показывает действие, которое доступно сейчас. Во время выполнения прогресс отображается на самой кнопке; после завершения она меняется на следующий шаг.

- **Установить** — сборка ещё не подготовлена.
- **Обновить** — доступна другая проверенная версия сборки.
- **Отменить** — загрузка или подготовка выполняется; остановите её кнопкой, а не удалением файлов.
- **Играть** — сборка готова к запуску.
- **Стоп** — игра запущена; используйте действие, чтобы остановить её штатно.
- **Проверка / подготовка** — дополнительные команды доступны в меню. Проверка целостности только читает файлы и показывает расхождения.

Если появляется ошибка, кнопка не должна скрывать её: откройте сообщение и следуйте инструкции. Для повторной проверки используйте команду проверки сборки.
