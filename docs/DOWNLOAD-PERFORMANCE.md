# Диагностика скорости установки

Предел по умолчанию — 0 («без ограничения»). При этом тариф 100 Мбит/с означает теоретически около 12,5 МБ/с, а не 100 МБ/с; реальная скорость зависит от CDN, задержки, диска и нагрузки. Просмотр счётчика файлов не является измерением скорости сети.

У установки несколько этапов:

- `.mrpack` — один сетевой поток; размер и скорость ограничены отдающим сервером. Архив ещё проверяется и распаковывается.
- Файлы Modrinth/packwiz обрабатываются с максимумом в восемь одновременных задач, с немедленным заполнением освободившихся слотов. В это число входят и локальные `overrides`, которые копируются и проверяются, а не скачиваются. Лимит настройки общий для сетевых потоков, а не отдельный для каждого.
- Проверка, копирование и применение тысяч файлов зависят от диска и антивируса, а не только от интернета.
- Установщик Minecraft (`mc-launcher-core` 0.1.2) использует собственный механизм. В опубликованном исходном коде `execute_plan` загрузки идут последовательно; это возможное узкое место при тысячах мелких ресурсов. Этот механизм данным изменением не ускорен и настройкой скорости не ограничивается.
- При повторном запуске источника проверяются актуальные корневые метаданные и целостность релиза. Неизменная сборка повторно не скачивается. Старой установке без сохранённой идентичности требуется одна полная загрузка; при изменении источника или повреждении релиза пока загружается вся сборка, не только изменённые файлы.

## Как замерять

На Windows выберите «Без ограничения», запишите длительность и видимый этап каждого шага, а для сети — фактическую скорость процесса в диспетчере задач. Сравнивайте одинаковые сборку, версию, диск и условия (первую и повторную установку отдельно). Для проверки только установщика сборки есть ignored online тест BattleArmory; он не измеряет загрузку Minecraft и не запускает игру. Нельзя делать вывод о пропускной способности только по общему времени или количеству обработанных файлов.
